# CS-340 Portfolio
Project Two Portfolio Reflection

1. How do you write programs that are maintainable, readable, and adaptable?

I learned that writing clean and organized code makes a program easier to understand, maintain, and update. In Project One, I created a Python CRUD module to perform database operations such as creating, reading, updating, and deleting records in MongoDB. In Project Two, I reused this module to connect the dashboard to the database. This saved time because I did not have to rewrite the database operations. Keeping the database code separate from the dashboard also made troubleshooting easier. In the future, I could reuse this CRUD module for other applications that need to manage data in MongoDB.

2. How do you approach a problem as a computer scientist?

I approach problems by understanding the requirements first and then breaking the work into smaller steps. For this project, I reviewed the requirements provided by Grazioso Salvare and worked on connecting the database to an interactive dashboard. Unlike some of my previous assignments, this project required me to combine database operations, Python programming, and data visualization into one application. I tested different parts of the program to identify errors and make sure everything worked correctly. In future projects, I would continue using this approach by planning the database structure, writing reusable code, and testing each feature before moving forward.

3. What do computer scientists do, and why does it matter?

Computer scientists develop software and systems that help people solve problems and work more efficiently. Their work is important because organizations depend on technology to manage information and make decisions. In this project, I developed a dashboard that allows Grazioso Salvare to search, filter, and view animal shelter records more easily. Instead of manually reviewing large amounts of data, users can find information about animals that meet specific rescue training criteria. This can help the organization identify suitable animals more efficiently and spend more time focusing on its rescue training goals. This project helped me understand how software development can solve practical problems for real organizations.
